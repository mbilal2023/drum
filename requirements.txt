# RicoLive React Native App - Requirements & Setup

## System Requirements

### Node.js & Package Manager
- Node.js v16.0.0 or higher
- npm v8.0.0 or higher (or yarn v1.22.0+)

### Development Environment
- Expo CLI: npm install -g @expo/cli
- EAS CLI (for building): npm install -g eas-cli

### Mobile Development
- For Android: Android Studio with SDK
- For iOS: Xcode (macOS only)

## Installation Steps

1. **Install Node.js Dependencies**
   ```bash
   npm install
   ```

2. **Install Expo CLI (if not already installed)**
   ```bash
   npm install -g @expo/cli
   ```

3. **Install EAS CLI (for building APKs)**
   ```bash
   npm install -g eas-cli
   ```

4. **Configure API Backend**
   - Open `src/services/api.js`
   - Update `API_BASE_URL` with your backend URL

5. **Start Development Server**
   ```bash
   npm start
   ```

## Building APK

### Setup EAS Build
1. Create Expo account at expo.dev
2. Login to EAS: `eas login`
3. Configure project: `eas build:configure`

### Build Commands
- Development APK: `eas build --platform android --profile development`
- Production APK: `eas build --platform android --profile production`

## Troubleshooting

### Common Issues

1. **Metro bundler issues**
   ```bash
   npx expo start --clear
   ```

2. **iOS build issues (macOS only)**
   ```bash
   cd ios && pod install && cd ..
   ```

3. **Android build issues**
   - Ensure Android Studio is properly installed
   - Check Android SDK path in environment variables

4. **Package conflicts**
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

### Environment Variables

Create `.env` file in root directory (optional):
```
API_BASE_URL=https://your-api-url.com/api
APP_NAME=RicoLive
```

## Testing

### Run on Physical Device
1. Install Expo Go app from app store
2. Scan QR code from `npm start`

### Run on Emulator
- Android: `npm run android`
- iOS: `npm run ios`
